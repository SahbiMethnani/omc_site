## About This Website

This repository contains the source code for the official OMC company website.

Built with **React** and **Vite**, the website serves as OMC's digital presence, introducing the company's expertise, showcasing its vision, and providing a point of contact for potential clients, partners, and collaborators.

### Tech Stack

- **React** — Component-based user interface development.
- **Vite** — Fast development environment and optimized build tooling.
- **JavaScript / JSX** — Application logic and interface structure.
- **CSS** — Styling and responsive user interface design.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm, included with Node.js

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd <project-directory>
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Vite will provide a local URL where you can preview the website.

### Production Build

To generate an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
